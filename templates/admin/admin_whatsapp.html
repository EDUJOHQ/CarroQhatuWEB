Sigue estos pasos para conectar tu celular:
  1. Abre la aplicación de WhatsApp en tu teléfono celular.
  2. Toca el icono de Menú (tres puntos) en Android o ve a Configuración en iPhone.
  3. Selecciona la opción Dispositivos vinculados (Linked Devices).
  4. Haz clic en Vincular un dispositivo y escanea el código QR que se muestra a la izquierda de inmediato.
  5. Una vez escaneado, la página detectará automáticamente la vinculación.
¿Por qué sale "No se pudo vincular el dispositivo"?
  • Sesión caducada / atascada: Haz clic en el botón amarillo Solucionar Error (Reiniciar Sesión) para generar un nuevo código.
  • Brillo del monitor: Aumenta el brillo de tu pantalla para que la cámara del celular enfoque con claridad.
  • Cerrar la cámara de WhatsApp: En tu teléfono, regresa a la pantalla anterior y vuelve a pulsar "Vincular dispositivo" antes de escanear.
  • Límite de dispositivos: Si tienes 4 dispositivos ya vinculados en tu WhatsApp, desvincula uno de ellos desde tu celular.

Configuración del Webhook

Usa estos datos para enlazar la API de Meta Cloud o Twilio con tu servidor de CarroQhatu. Esta URL recibe los mensajes entrantes en tiempo real.

* Nota: Si estás ejecutando el servidor de forma local, recuerda cambiar la raíz (ej. 127.0.0.1) por la dirección pública HTTPS provista por ngrok.
Token de seguridad que ingresas en la consola de Meta Developers para verificar que eres dueño del servidor de webhook.
Guía paso a paso para probar en tu Teléfono Celular
1
Configurar las Variables de Entorno

Añade tus tokens en el archivo .env de la raíz del proyecto. Asegúrate de tener activa una llave de IA (GEMINI_API_KEY o OPENAI_API_KEY) para que el agente responda con inteligencia real.

2
Iniciar el Servidor Local y Exponer con ngrok

Dado que WhatsApp requiere una URL pública y segura (HTTPS) para enviarte mensajes, ejecuta el siguiente comando en tu consola para crear un túnel dinámico:

ngrok http 5000
Copia la dirección provista por ngrok que inicia con https://....
3
Configurar el Webhook en la Consola

Pega tu URL pública (ejemplo: https://tu-subdominio.ngrok-free.app/api/whatsapp/webhook) y el Token de Verificación en la configuración de webhooks de Meta o Twilio, y selecciona la suscripción al evento messages.

4
¡Listo! Envía un mensaje desde tu celular

Escribe cualquier consulta (ej. "Hola, ¿tienes algún Toyota Hilux en stock y cuál es el precio?"). El agente de WhatsApp IA responderá automáticamente con los datos de tu catálogo, y registrará a la persona en la base de datos de Solicitudes al capturar sus datos.

Formato de Variables de Entorno (.env)

Abre el archivo .env y agrega o edita los siguientes parámetros según el proveedor que elijas: 

# CONFIGURACIÓN META CLOUD API (RECOMENDADO)
WHATSAPP_ACCESS_TOKEN=tu_token_de_acceso_temporal_o_permanente
WHATSAPP_PHONE_NUMBER_ID=tu_identificador_de_numero_de_telefono
WHATSAPP_VERIFY_TOKEN={{ verify_token }}

# CONFIGURACIÓN TWILIO API (OPCIONAL/ALTERNATIVA)
TWILIO_ACCOUNT_SID=tu_twilio_account_sid
TWILIO_AUTH_TOKEN=tu_twilio_auth_token
TWILIO_WHATSAPP_FROM=whatsapp:+14155238886
